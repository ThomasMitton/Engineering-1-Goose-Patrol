## About

A 2D, top-down game that sees the player try to escape a swarm of geese attacking them on campus.

Written in Java with LibGDX.

## Controls

* WASD/Arrow keys: movement
* Num keys: use item
* M: use map
* ENTER: press by bus to finish game
* ESC: pause
